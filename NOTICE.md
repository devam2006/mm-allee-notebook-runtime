# Public notebook runtime

Published at Devam's request for anonymous professor/student access to the mathematical modelling notebook, required code, synthetic data and figures. This companion repository contains selected project artifacts, without the private development repository's history, discussions or reviews.

All population data are synthetic. The computational integration has been tested, but public availability does not imply all human scientific reviews or final submission requirements are complete. The editable report is maintained separately in Overleaf.
